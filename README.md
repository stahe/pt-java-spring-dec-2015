## 📚 Sobre este documento

Este material didático destina-se a estudantes iniciantes no âmbito universitário. Combina conceitos teóricos do curso com exercícios práticos.

### Objetivos de aprendizagem

O objetivo principal é ensinar a linguagem Java numa perspetiva **profissional**. Por este motivo, o curso baseia-se em grande parte no framework **[Spring](http://spring.io/)**, uma tecnologia utilizada no desenvolvimento **JEE** (Java Enterprise Edition).

Logicamente, este módulo serve como introdução prévia à realização de um curso especializado em JEE.
